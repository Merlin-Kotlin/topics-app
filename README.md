# Topics App 📚

An Android app built with **Kotlin** and **Jetpack Compose** as part of the
[Android Basics with Compose](https://developer.android.com/courses) course by Google.

## 🚀 Features
- Displays a grid of topics, each showing an image, name, and course count
- Built entirely with Jetpack Compose (no XML)
- Responsive 2-column scrollable grid using LazyVerticalGrid
- Handles system bar insets for a clean edge-to-edge UI

## 🏗️ What I Learned
- Creating data classes in Kotlin to model app data
- Separating data from UI using a DataSource object
- Building reusable composables (TopicCard, TopicsGrid)
- Using LazyVerticalGrid for efficient list rendering
- Handling window insets for proper status bar spacing
- Using resource IDs (R.drawable, R.string) the Android way
